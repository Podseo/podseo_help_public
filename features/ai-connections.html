AI Connections ​

Ask Claude, ChatGPT or Cursor About Your PodSEO Data ​

AI connections let you connect an AI assistant you already use, such as Claude, ChatGPT or Cursor, to your PodSEO account. Once connected, you can ask the assistant questions in your own words ("Which of my tracked keywords dropped on Spotify this month?", "Compare my last five episodes' downloads", "How does my Apple ranking compare with my main competitor's?") and it answers with your real PodSEO data: your podcasts, tracked keywords and rankings, competitors, ratings, AI visibility and the analytics you've connected.

It's useful when you want to combine numbers that live on different PodSEO pages, write a report in your own format, or think through a strategy with an assistant that can look up the facts as you talk.

Who can use it: AI connections are included in every paid plan (Podcaster, Producer, Agency, Enterprise). On the Free plan, PodSEO shows an upgrade page when you try to connect.

Read-only: the assistant can read your PodSEO data. It can't change anything: it can't add or remove keywords, edit competitors, change your Planner or settings, or publish anything.

What You Need ​

  • A PodSEO account on a paid plan (or membership in an organization on a paid plan).
  • An AI assistant that supports custom connectors (also called MCP servers or custom apps). Claude, ChatGPT and Cursor all do, though availability can depend on your plan with that assistant.
  • The PodSEO server URL:
https://mcp.podseo.com/mcp

You can also copy the URL from Settings → AI connections in PodSEO.

How to Connect ​

Every assistant follows the same pattern: you add PodSEO using the server URL, sign in to PodSEO, and approve the connection. The menus differ between assistants and can change. The steps below were checked against their official setup guides on October 22, 2026.

Claude (claude.ai and the Claude Desktop app) ​

  1. Open Customize → Connectors, then + Add → Add custom connector.
  2. Name it "PodSEO", paste https://mcp.podseo.com/mcp as the server URL, and continue.
  3. Choose Sign in now and Use Claude’s published identity when asked about authentication, then finish adding the connector.
  4. Sign in to PodSEO and approve the connection when prompted. If the connector is listed but not connected, click Connect.
  5. Enable PodSEO for your conversation from the + → Connectors menu, then ask your question.

On Team and Enterprise, an owner or another permitted administrator must first add it through Organization settings → Connectors → Add → Custom → Web. Members then connect individually. Remote connectors are available across Claude web, Desktop and mobile on the same account.

See Claude’s official connector guide for current menus and workspace permissions.

Claude Code ​

  1. In your terminal, add PodSEO as a remote server:
    claude mcp add --transport http podseo https://mcp.podseo.com/mcp
  2. Start Claude Code and run /mcp, select podseo and choose to authenticate. Your browser opens PodSEO: sign in and approve the connection.

See Claude Code’s MCP guide for configuration options.

ChatGPT ​

  1. On ChatGPT’s website, open Plugins, select +, then Add custom MCP server.
  2. Name it "PodSEO" and enter https://mcp.podseo.com/mcp under Connection → Server URL.
  3. Choose OAuth authentication. Leave the client ID and client secret blank; select CIMD if asked how to identify the client.
  4. Review the connection notice and select Create as a plugin. Find PodSEO in your plugins and install it.
  5. In a chat, type @ and select PodSEO. When prompted, sign in to PodSEO and approve the connection.

Workspace permissions and security settings can restrict custom plugins. If the option is unavailable, check with your workspace administrator. See OpenAI’s custom MCP setup guide for the current process.

Cursor ​

Manage MCP servers from Customize, or configure PodSEO in mcp.json:

  1. Open ~/.cursor/mcp.json for access across projects, or .cursor/mcp.json within one project.
  2. Add the podseo entry below. If the file already lists servers, keep them and add podseo inside the existing mcpServers object.
    json
    {
  "mcpServers": {
    "podseo": {
      "url": "https://mcp.podseo.com/mcp"
    }
  }
}
  3. Save the file and follow Cursor’s sign-in prompt. In your browser, sign in to PodSEO and approve the connection.

No API key or manually created client credentials are needed. See Cursor’s MCP guide for current setup options.

Other assistants ​

For another assistant, check that it supports Streamable HTTP and OAuth sign-in for remote MCP servers. Add https://mcp.podseo.com/mcp as the server URL, then sign in to PodSEO and approve. Setup varies by client; the instructions above cover Claude, Claude Code, ChatGPT and Cursor.

Approving the Connection ​

When the assistant sends you to PodSEO, sign in with your usual PodSEO login. PodSEO then shows a consent page that:

  • Names the assistant that is asking to connect. When PodSEO can verify where the request comes from (for example, Claude or ChatGPT), it says so. If you see a warning that PodSEO hasn't verified the app, only continue if you started the connection yourself and expect to be sent back to the site shown.
  • Lets you choose the account the assistant can read: your personal account or an organization you belong to. Accounts that aren't on a paid plan are shown but can't be selected.
  • Confirms that the assistant can only read, and that the analytics connected to that account are included (YouTube data is not).

Click Allow to finish. You're sent back to the assistant and can start asking questions.

One account per assistant. Each assistant reads one PodSEO account at a time. To have it read a different account (for example, your organization instead of your personal account), connect it again and pick the other account: the earlier connection is replaced.

In an organization, the assistant sees what you can see in PodSEO for that account. If you've been given access to only some of the organization's podcasts, the assistant sees only those.

What the Assistant Can Read ​

The assistant can read the same information PodSEO shows you in the app, for the account you approved:

  • Your podcasts: details, metadata and episodes, and the history of changes to your episode titles and descriptions.
  • Keywords and rankings: your tracked keywords and how your show ranks for them on Apple Podcasts, Spotify, Amazon Music, YouTube Music and YouTube, the search results for your tracked keywords, your episodes' keyword rankings and episode SEO scores.
  • Competitors: your tracked competitors and how they rank for your tracked keywords.
  • Ratings and reviews: ratings across platforms and Apple Podcasts reviews.
  • Charts and editorial: your chart positions and editorial features.
  • Visibility: your Visibility Score and rank, and their history.
  • AI visibility: whether ChatGPT, Claude, Perplexity and Gemini mention your podcast, and the weekly trend (see AI Mentions).
  • Related podcasts, your Planner, your positioning, keyword groups, recommendations and distribution health.
  • Your plan: plan limits and credits.
  • Connected analytics (see Analytics Connections):
    • Downloads and audience from your podcast host (Spreaker, Buzzsprout), OP3 and hopr.fm
    • Spotify for Creators: plays, listeners, impressions and discovery, retention, benchmarks and episode details
    • Apple Podcasts Connect: plays, listeners, followers, episodes and reports

What it can't read ​

  • YouTube analytics: your YouTube channel's data from YouTube Insights is not shared with AI assistants. The assistant can only tell whether YouTube is connected.
  • Keywords and competitors you don't track: the assistant works with your tracked keywords and competitors, within your plan's limits. It can't look up new keywords or research shows you haven't added.
  • Anything beyond your plan: if your account is over a plan limit (for example after moving to a smaller plan), the podcasts, keywords and competitors above the limit aren't readable, just as in the app.
  • Analytics you haven't connected or have disconnected: a disconnected source shows no numbers.
  • Other people's accounts: only the account you approved.

Your data, the assistant's analysis ​

PodSEO gives the assistant your data and PodSEO's own scores (such as the Visibility Score and episode SEO scores). The analysis, summaries and advice you get in the conversation are written by the assistant itself, not by PodSEO. If you want PodSEO's own guidance, use LUCIA inside the app.

Privacy ​

  • PodSEO sends data to the assistant only when the assistant asks for it on your behalf, while you're using it.
  • Once the assistant receives your data, the assistant's provider (for example Anthropic for Claude or OpenAI for ChatGPT) handles it under its own terms and privacy policy, including any copies kept in your conversations.
  • YouTube data is never shared with AI assistants.

Read the full details in the AI Assistant Connections section of the PodSEO Privacy Policy.

Disconnecting ​

You can disconnect an assistant at any time, in any of these ways:

  • In PodSEO: open Settings → AI connections, find the assistant and click Disconnect. The assistant loses access within a minute.
  • In the assistant: remove the PodSEO connector from the assistant's connector or integration settings.
  • By email: write to info@podseo.com and we'll disconnect it for you.

After you disconnect, PodSEO sends the assistant no further data. Deleting your PodSEO account also removes all AI connections.

Troubleshooting ​

The assistant says AI connections need a paid plan ​

The account you approved isn't on a paid plan, for example because the subscription ended or was moved to the Free plan. Upgrade and the connection works again; you don't need to reconnect.

The consent page says AI assistant connections need a paid plan ​

The PodSEO account you signed in with isn't on a paid plan. Upgrade, or, if you belong to an organization on a paid plan, make sure you're signing in with the login that belongs to it and pick the organization on the consent page.

The assistant can't find a podcast, keyword or competitor ​

It only reads what's tracked in the account you approved and within your plan's limits. Check that the podcast, keyword or competitor is tracked in PodSEO. If your account is over a plan limit, the items above the limit aren't readable until you upgrade or reduce what you track. In an organization, check that you have access to that podcast.

The assistant says my Spotify, Apple or host numbers aren't available ​

Connect that source in PodSEO first, on the Analytics page. If you disconnected it, its numbers aren't shared. YouTube analytics are never shared.

The numbers look out of date ​

The assistant sees the same numbers PodSEO has, as of PodSEO's latest update for each source, and it receives the date of that data. Ask the assistant which date the numbers refer to. Each source updates on its own schedule (see Analytics Connections for how fresh each one is).

The assistant reads the wrong account ​

Each assistant reads the account you picked when you approved it. Connect the assistant again and choose the other account on the consent page.

The connection stopped working ​

If you disconnected the assistant in PodSEO, or removed and re-added the connector, reconnect it from the assistant's connector settings and approve again. If it keeps failing, contact us from Settings → Contact Us.

FAQ ​

Can the assistant change my keywords, competitors or episodes? ​

No. The connection is read-only. The assistant can read your data but can't add, remove or edit anything in PodSEO, and it can't publish anything.

Can ChatGPT or Claude see my Spotify and Apple stats? ​

Yes, if you've connected Spotify for Creators or Apple Podcasts Connect in PodSEO's Analytics page. The same goes for your host (Spreaker, Buzzsprout), OP3 and hopr.fm. YouTube analytics aren't shared.

Is it included in my plan? ​

AI connections are included in every paid plan, with no extra charge. They aren't available on the Free plan.

Does using the assistant cost PodSEO credits? ​

No. Reading your data through an AI connection doesn't use credits.

Can I connect more than one assistant? ​

Yes. You can connect Claude, ChatGPT and Cursor at the same time. Each one reads the account you approved for it, and you can disconnect each one separately.

Is this the same as LUCIA? ​

No. LUCIA is PodSEO's own assistant, built into the app, with PodSEO's guidance and the ability to make supported changes for you. AI connections let an outside assistant you choose read your PodSEO data, without making changes.

Pro Tips ​

  • Start by asking the assistant to list your podcasts in PodSEO: it confirms the connection reads the right account.
  • Ask comparative questions that span several PodSEO pages, such as "Which tracked keywords improved on Apple but dropped on Spotify in the last month?"
  • When you ask about downloads, say which source you mean (your host, hopr.fm, Spotify, Apple): each counts something different, so the numbers aren't meant to be added together.
  • Ask the assistant for the date of the data it's using, especially for analytics, before drawing conclusions.
  • Use the assistant to draft reports for sponsors or your team, then check the key figures against PodSEO's pages.
